# Sep 1, 2026: Public version plan

**Problem**
- Files spread over several computers; a dead disk means lost work.
- No Google Drive for Desktop on Linux.
- Bukluran ng Kalinga staff computers need backup without IT help.

**Idea:** one small free Go app that backs up folders to your own Google Drive, keeps one folder the same on all your computers, and restores files and old versions.

**Users:** Linux, Windows, macOS users with Google Drive; Bukluran staff (no-setup edition).

**Rules**
- Never lose data. In doubt, keep both copies.
- Your own Google account and key. Files go nowhere else.
- Low CPU. Memory sized to the computer.
- One-command install.
