Step 1 · Connect to Google

One time only, free, about 5 minutes. Open each step for details.

  1. Create a Google Cloud project
    • Project name: GoBridgeSync. Leave the project ID and organization as they are.
    • Click Create, then make sure GoBridgeSync is selected at the top of the page.
    • If you see "Google Cloud access blocked", turn on 2-Step Verification, sign out, and sign in again.
    • Skip any "free trial" or billing offer. It is not needed.
  2. Enable the Google Drive API
    • Click Enable. If you see Manage instead, it is already on.
  3. Set up the consent screen
    • Click Get started. App name: GoBridgeSync. Support email: yours.
    • Audience: External. Contact email: yours. Accept the policy and click Create.
    • Open Audience → Test users → Add users and add the Google account you will sync.
    • Keep the status on Testing. Do not publish.
  4. Create an OAuth client
    • Application type: Desktop app. Name: GoBridgeSync Desktop.
    • Leave "Use this client for an AI-powered agent" off.
    • Click Create, then Download JSON. Keep this file private.

Step 2 · Sign in

Pick the account you added as a test user. When Google says "Google hasn't verified this app", choose Continue: it is your own app. You come back here automatically.
